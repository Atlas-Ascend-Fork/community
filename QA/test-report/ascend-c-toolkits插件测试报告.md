# asc-vscode仓开源测试报告
## 1. 概述

本报告为 Ascend C Toolkits 插件开源测试报告，在该阶段完成了基于Ascend C Toolkits 1.5.7版本开源包的测试，覆盖所有功能特性及文档，测试过程中执行覆盖率达到100%。

Ascend C Toolkits 是华为 CANN 团队的 VSCode 扩展，为 Ascend C 语言提供算子开发、调试和
性能分析的一体化平台，帮助开发者快速上手算子开发。
## 2. 版本测试信息

- Ascend C Toolkits 插件版本：1.5.7
- 本地操作系统：Windows/Linux
- IDE 版本：Visual Studio Code 1.96.4
## 3. 测试结论

**Ascend C Toolkits 1.5.7** 本次评估详情：

- 版本修改范围包含新增特性功能，功能用例全量覆盖;
- 版本新增执行优化功能，支持与CANN-work多窗口对话，性能数据预览、通信等数据可视化功能;

**整体结论：满足版本发布要求**
