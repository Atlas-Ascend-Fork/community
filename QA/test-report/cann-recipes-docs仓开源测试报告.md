# cann-recipes-docs 仓开源测试报告

## 1. 概述

本报告用于 `cann-recipes-docs` 新仓开源质量评估。测试覆盖推理、训练、具身智能等领域技术文档，检查中英文档配对、网站静态元数据、相对文件链接、README 可用性、开源合规文件。
仓库定位为开源技术文档仓库，不交付模型、算子或二进制，不涉及 NPU 硬件、CANN/PyTorch 运行环境、数值精度和模型性能测试。

## 2. 版本测试信息
本仓为开源技术文档仓库，不涉及软件的交付，仅有少量代码用于网站静态元素的校验。
Python版本：3.11

## 3.测试结论
通过。
仓库共包含 110 个 Markdown 文件，其中技术正文 98 篇：中文 49 篇、英文 49 篇，全部形成同路径、同文件名配对。按内容域统计，推理 56 篇、训练 12 篇、具身智能 22 篇、CANN 原子特性 8 篇。仓库另有 406 个图片资源，包括 397 个 PNG/JPG/JPEG 位图和 9 个 SVG 文件。静态元素校验通过。
