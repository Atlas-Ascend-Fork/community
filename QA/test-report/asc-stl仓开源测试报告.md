# asc-stl仓开源测试报告（v1.0.0）

## 1. 概述

本报告覆盖 asc-stl 仓开源前自验证测试。被测对象为 `cann/asc-stl` master 分支开源版本的全部对外头文件及配套测试：对外头文件 109 个（C++ 标准库接口 74 个、昇腾扩展接口 23 个、Runtime 接口 12 个），仓库头文件共 796 个，用例适用性由 `test/metadata/headers.json`（796 条）全量映射，对外头文件用例覆盖率 100%。

### 1.1 特性清单

ASC-STL 是面向昇腾设备 Kernel 编程的纯头文件 C++ 库，为 Host 与 Kernel 代码提供统一的对外头文件组织，对外接口分为 C++ 标准库接口（`asc::std`，`<asc/std/...>`）、昇腾扩展接口（`asc`，`<asc/...>`）与 Runtime 接口（`asc`，`<asc/...>`）三层，共 29 类能力模块：

| 层 | 能力模块 |
| --- | --- |
| C++ 标准库接口 | 语言支持库；概念库；诊断库；内存管理库；元编程库；通用工具库；容器库；迭代器库；范围库；算法库；字符串库；文本处理库；数值库；日期和时间库；输入/输出库；并发支持库 |
| 昇腾扩展接口 | 设备原子操作与线程同步；异步数据搬运流水线；地址空间与内存视图；多维数据视图与搬运；设备执行层次、集体操作与动态任务获取；Device 并行算法与参数包装；算法函数对象、操作属性与迭代器适配器；位操作、数学与数值计算、伪随机数；类型特征、通用工具与版本检测 |
| Runtime 接口 | 设备、Stream 与 Event 管理；核函数调用；Device 执行策略、执行要求与提交状态；内存资源、内存池与缓冲区 |

### 1.2 解决问题列表

首个开源版本，不涉及。
