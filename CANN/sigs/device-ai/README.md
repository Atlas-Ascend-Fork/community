# device-ai SIG

### 🌟 简介 (Introduction)

欢迎来到**device-ai SIG**！我们致力于基于CANN在Kirin、昇腾等端、边芯片上，提供轻量、低延迟、低内存占用的LLM、VLM等大模型推理能力，让大模型真正在端侧与边侧设备上跑起来、跑得快、跑得省。

**已开源仓的列表：**

| 项目名称 | 功能领域 |
|----------|----------|
| [cann-device-lm](https://gitcode.com/cann/cann-device-lm) | 端侧/边侧大模型转换工具与端到端推理引擎 |

### 🎯 愿景与使命 (Vision & Mission)

我们希望让大模型推理不再局限于云端：在手机、终端、边缘设备上，也能享受到流畅的大模型对话与多模态体验。

我们的使命是：**轻量部署，端侧智能。**

我们希望通过提供轻量、低延迟、低内存占用的端到端大模型推理能力，帮助开发者把LLM/VLM模型高效落地到Kirin、昇腾等端、边芯片，让AI能力触手可及。

### 🛠️ 我们主要关注 (Scope of Work)

我们专注于以下内容的建设与维护，每一个方向都需要您的参与：

*   **大模型转换工具**：支持将三方大模型转换为CANN LM大模型，包含量化、脚本优化、模型导出等步骤，让模型适配端、边侧的资源约束。
*   **大模型推理引擎**：将LLM/VLM大模型tokenizer、embedding、prefill执行、decode执行、采样等步骤封装为统一的端到端工作流，提供端到端推理Pipeline。模型/算子编译、加载运行调用CANN的能力。
*   **端侧性能优化**：围绕轻量、低延迟、低内存占用，持续打磨端、边芯片上的大模型推理性能。

### 🤝 加入我们 (Join Us)

在这里，您不仅仅是一个代码贡献者，更是端侧AI生态的建设者：

*   **技术成长**：直接与端侧大模型推理专家交流，深入理解模型转换、量化、图编译、算子与运行时在端、边芯片上的协同优化原理。
*   **影响力**：您的代码将让大模型跑在千家万户的终端设备上，成为端侧智能落地的参考标准。
*   **荣誉激励**：优秀的贡献者将获得优秀贡献者认证，成为您简历上亮眼的一笔。
